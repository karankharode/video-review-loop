## Flags

- **The Odyssey comparison rests on one outlet.** It's the load-bearing proof beat, so verify it against a second source before publishing. If it doesn't hold, swap in any other recent A-certificate release that cleared uncut — the argument survives, the example is replaceable.
- **"Nobody banned it" is precise, not rhetorical.** CBFC certifies; it does not ban. Refusal of certification is a separate and much rarer action. Don't let an edit soften this into "wasn't really banned" — the precision is the video.
- **Tone guard.** This is deliberately *not* an anti-CBFC video. It explains a mechanism and declines the outrage frame. If a rewrite drifts toward "look what they took from us", it has become the thing it was correcting — and it walks into the partisan-politics red light in `BRAND.md`.
- The 13+ threshold reflects current UA sub-categorisation. The four-tier U/UA/A/S structure is the statutory base.
